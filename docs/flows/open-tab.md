# Fluxo — Abrir Conta

## Cliente já conhecido

1. Funcionário busca nome/apelido ou usa futuro identificador NFC.
2. Sistema mostra status de relacionamento e eventual saldo anterior.
3. Funcionário toca `Abrir conta`.
4. Sistema cria Tab com limite operacional derivado do Relationship.
5. Staff pode lançar consumo imediatamente.

## Cliente novo

1. `+ Novo cliente`.
2. Informar nome/apelido.
3. Telefone é opcional.
4. Selecionar relacionamento inicial: Visitor / Known / Regular / House.
5. Sistema mostra o limite padrão associado antes de confirmar.
6. Criar customer + relationship + tab.

## Regra

A escolha inicial humana é bootstrap. O MVP não promove/rebaixa automaticamente.
