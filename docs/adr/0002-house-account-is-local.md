# ADR 0002 — Relationship Is Local to the Venue

**Status:** Accepted

## Decisão

`REGULAR` ou `HOUSE` pertencem à relação entre um customer e um venue.

Não existe no MVP uma reputação global do cliente entre estabelecimentos.

## Motivo

“Da casa” é uma relação social contextual. Transformá-la em reputação portátil cria problemas de consentimento, privacidade, explicabilidade e risco que não são necessários para provar o MVP.
