# Acceptance — Spec 001

- [x] Staff abre uma Tab sem selecionar mesa.
- [x] Staff pode opcionalmente associar/mover a Tab entre ServicePoints.
- [x] Pedido com produtos ativos é confirmado com snapshot de preço.
- [x] Cada item confirmado gera efeito financeiro exatamente uma vez.
- [x] Estados operacionais registram timestamps.
- [x] Cancelamento pós-confirmação não apaga histórico e exige auditoria.
- [x] Pagamento manual reduz exposure.
- [x] Tab com exposure zero pode ser fechada.
- [x] Caixa resume recebimentos por método.
- [x] Staff navega entre Agora, Pedir, Contas e Caixa com alvos adequados a toque.
- [x] Modo pico exibe somente a fila operacional essencial, ordenada pela maior espera.
- [x] A interface informa quando está sem sinal, enfileira pedidos e dinheiro e sincroniza sem duplicar; Pix e cartão aguardam conexão.
- [x] Cozinha visualiza itens pendentes por pedido, destino, idade e urgência.
